Referanslar
Bu referanslar dosyası, WhatToDo web uygulamasının geliştirilmesi ve tasarımı sırasında kullanılan kaynakları içermektedir. Aşağıda listelenen kaynaklar, projenin oluşturulmasında önemli bir rol oynamıştır.

MDN Web Docs: Web geliştirme teknolojileri hakkında kapsamlı ve güncel bilgiler sunan Mozilla Developer Network dokümantasyonları.


W3Schools: HTML, CSS ve JavaScript gibi web teknolojileriyle ilgili detaylı öğreticiler ve referanslar sunan çevrimiçi bir kaynak.


Stack Overflow: Yazılım geliştirmeyle ilgili sorularınızı sormak ve cevaplamak için topluluk tabanlı bir platform.


GitHub: Proje dosyalarının depolanması, sürüm kontrolü ve işbirliği için kullanılan popüler bir platform.
*https://github.com/niinpatel/calendarHTML-Javascript // Sitedeki takvim özelliği için bu kod baz alınmıştır.


Netlify: Web uygulamalarını dağıtmak ve barındırmak için kullanılan bir platform. WhatToDo web uygulamasının canlı yayınlanması için kullanılmıştır.


Kocaeli Üniversitesi Web Teknolojileri Dersi: WhatToDo web uygulaması projesinin geliştirilmesi için ders materyalleri ve rehberlik.
