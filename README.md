# WhatToDo Web Uygulaması

Bu web uygulaması, görevleri ve yapılacaklar listelerini yönetmek için basit bir araç sağlar. Kullanıcılar görev ekleyebilir, düzenleyebilir, silebilir ve tamamlanmış olarak işaretleyebilirler. Ayrıca, görevleri tamamlanma durumuna göre filtreleyebilirler. Bazı motive edici içeriklere erişebilir ve diğer kullanıcıların yazdığı geri dönütleri okuyabilirler.

Bu uygulama HTML, CSS ve JavaScript kullanılarak geliştirilmiştir. DOM manipülasyonu tekniğiyle dinamik olarak içerik ve yapı güncellemeleri sağlanmaktadır.

## Uygulama Linki

Uygulamayı canlı olarak şu adresten görüntüleyebilirsiniz: [WhatToDo](whatto-do-kou-wt.netlify.app)

## Özellikler

- Görev ekleme, düzenleme, silme
- Görevleri tamamlama işaretleme
- Tamamlanmış ve tamamlanmamış görevleri filtreleme

## Kurulum

Projeyi yerel makinenize klonlayarak veya dosyaları indirerek kurabilirsiniz.


## Kullanım

1. İndirdiğiniz veya klonladığınız dosyaları bir metin düzenleyicisi veya kod editörü ile açın.
2. Ana dizindeki `index.html` dosyasını bir web tarayıcısında açarak uygulamayı başlatın.
3. Uygulamayı kullanmaya başlayın, görev ekleyin, düzenleyin, silin ve tamamlayın.
